# Vijay Duhan Portfolio Website

A multi-page portfolio website for the Digital Portfolio final assignment.

## Pages
- `index.html` — Home and overview
- `about.html` — About Me, skills, resume
- `projects.html` — All project cards
- `student-planner.html` — Student Life Planner Dashboard case study
- `cafe-website.html` — Café Website case study
- `imd-showcase.html` — IMD Showcase Website case study
- `libryx-app.html` — Libryx App case study
- `contact.html` — Contact form and links

## How to use
1. Open the folder in VS Code.
2. Open `index.html` with Live Server.
3. Replace or add images inside `assets/images/` if needed.
4. Keep your resume in `assets/docs/Vijay-Duhan-Resume.pdf`.
5. Push to GitHub.
6. Enable GitHub Pages from repository settings.

## GitHub Pages
Use the `main` branch and root folder for publishing.
